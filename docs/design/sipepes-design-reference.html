SIPEPES adalah website responsif, bukan aplikasi HP.

Referensi visual pendamping plan.md. Setiap halaman dirender dari markup yang sama di jendela browser laptop (1024 px) dan browser HP (375 px), memakai container query sehingga perilaku responsifnya nyata, bukan gambar terpisah. Palet fun, gerak smooth, font Montserrat.

Cara memakai file ini

  • Buka langsung di browser, tidak perlu build. Coba bagian Pratinjau responsif untuk melihat satu halaman di 375, 768, 1024, dan 1280 px.
  • Ikuti file ini untuk tata letak, warna, dan teks. Untuk aturan dan angka, plan.md yang berlaku bila berbeda.
  • Peta adalah ilustrasi SVG (implementasi: Leaflet + OSM). Foto placeholder. Data fiktif.
  • Kode halaman (W1, A3, dan seterusnya) dipakai di PR dan diskusi.

Halaman warga plan 7–8

Situs publik tanpa akun. Kiri: jendela laptop 1024 px. Kanan: browser HP 375 px. Keduanya markup yang sama. Halaman ditampilkan utuh dari header sampai footer.

Alur A: warga melapor
  • Hero berwarna dengan dua ajakan: "Laporkan Pencemaran" (Koral) dan "Lacak laporan". Di desktop, kanan hero menjelaskan tiga langkah.
  • Peta hanya laporan valid. Desktop: filter + daftar di kiri, peta di kanan, popup di marker. HP: chip filter, peta 300 px, lalu daftar.
  • Di HP navigasi pindah ke menu hamburger (W12). "Masuk admin" hanya di footer.
  • Desktop: area seret-dan-lepas foto. HP: dua tombol besar "Ambil foto" (kamera) dan "Pilih dari galeri".
  • Desktop menampilkan kolom samping tips. Di HP tips pindah ke dalam kartu.
  • Di HP tombol Kembali/Lanjut menempel di bawah layar (position: sticky).
  • Pin tetap di tengah, peta yang digeser. "Gunakan lokasi saya" memakai geolocation lalu flyTo.
  • Izin ditolak → pesan "Izin lokasi ditolak. Geser peta ke titik kejadian." Tidak ada koordinat acak.
  • Desktop dua kolom: isian wajib di kiri, "Kondisi lokasi" (opsional, dari wawancara GGP) di kanan. HP satu kolom.
  • "Ubah" kembali ke langkah terkait dengan gerak geser mundur. Saat kirim: tombol "Mengirim…" nonaktif; gagal → toast + "Coba lagi", isian tetap.
  • Centang tergambar + konfeti kecil sekali. Salin kode → toast. Bagikan memakai wa.me/?text= berisi kode dan tautan lacak.
Alur B: warga melacak
  • Input kosong saat dibuka. Desktop: input dan tombol sebaris. HP: bertumpuk.
  • Desktop dua kolom: status + linimasa, dan ringkasan laporan. Linimasa hanya dua tahap.
  • "Lihat di peta" membuka beranda dan terbang ke marker laporan ini.
  • Alasan dari admin tampil apa adanya. Ajakan membuat laporan baru.
  • Tidak pernah menampilkan laporan lain sebagai pengganti.
  • Panel turun dari bawah header, latar memudar. Tutup dengan × , Esc, atau ketuk latar.
Panduan
  • Empat kartu langkah: 4 kolom di desktop, 2 di tablet, 1 di HP.

Halaman admin plan 7–8

Area admin tetap website yang sama di /admin. Desktop: sidebar tetap. Di bawah 1024 px sidebar menjadi laci (A9). Latar abu-100 dengan aksen Ungu, lebih tenang dari situs warga.

Alur C: admin memverifikasi
  • Hanya email dan kata sandi. Salah → "Email atau kata sandi salah." Di HP panel ungu disembunyikan.
  • Angka dihitung dari data. Desktop: tabel. HP: kartu, filter lewat tombol "Filter".
  • Tab Menunggu urut paling lama di atas. Kosong → "Tidak ada laporan yang menunggu. Semua sudah diperiksa."
  • Dua kolom bila area konten ≥ 760 px (mis. desktop 1280). Lebih sempit (laptop 1024 dengan sidebar, tablet, HP) jadi satu kolom dengan urutan: foto, isian warga, keputusan, kondisi lokasi, lokasi, riwayat. Lihat di Pratinjau responsif.
  • Setelah keputusan: toast, status berubah halus, lalu buka laporan menunggu berikutnya.
  • Alasan wajib minimal 10 karakter. Desktop: dialog di tengah. HP: dialog menempel di bawah layar.
Alur D: peta, rekap, riwayat, data master
  • Hanya laporan valid. Desktop: kartu ringkas melayang di kanan peta. HP: kartu di bawah peta.
  • Tabel titik valid bisa diurutkan; di HP tabel digulir mendatar. Unduh → "Menyiapkan…", gagal → toast "Coba lagi".
  • Kolom sesuai NFR-5. Di HP setiap baris jadi kartu.
  • Nonaktifkan, bukan hapus. Endpoint belum ada di backend: bangun dengan mock dulu.
  • Sidebar yang sama, meluncur dari kiri (300 ms). Latar memudar.
